Справка по Схемокодеру

Добро пожаловать в Схемокодер — среду визуального программирования, где на примере HTML и JavaScript можно создавать веб-страницы, выстраивая логику из отдельных элементов.

Для работы со средой выбирайте тип элемента: «Контейнер», «Атрибут», «Рефлекс» или «Функционал», вводите команды в поле ниже и подбирайте контейнеры для месторасположения команды. Рефлексы в дополнение можно размещать в атрибутах. Пример работы представлен в видео-презентации.

Формирование HTML-страницы

Контейнеры — структура страницы

Контейнеры определяют структуру страницы и позволяют объединять элементы в группы. Например:

  • div — обозначает отдельный блок страницы.
  • table — для обозначения что будет таблица.
  • tr — строки таблицы.
  • td — ячейки таблицы.
  • h1 — заголовок.

Рефлексы — содержимое

Рефлексы задают текстовое содержимое.
Для добавления текста используется команда innerText: TEXT, где TEXT заменяется нужным текстом.

Атрибуты — оформление

Для оформления элементов используются CSS-стили. Например:

  • color: green — задаёт зелёный цвет текста.
  • text-shadow: 0 0 15px red — добавляет тексту красную тень со свечением.
  • background-image: url("./modules/background-tile.png") — задает фон в виде картинки.

Управление выполнением схемы

Запуск и модульные контейнеры

При запуске элементы обрабатываются последовательно, в порядке их расположения в схеме. Контейнеры верхнего уровня пропускаются при автоматическом проходе и получают статус модульных. Название такого контейнера принимает формат TAG_NAME модульный. Модульные контейнеры можно подключать из других элементов схемы.

Подключение модульных контейнеров

Для подключения модульного контейнера используется команда функционала подключить {id: N}, где N — ID нужного контейнера. Например, подключить {id: 1} подключает модульный контейнер с ID 1.

Ограничения запуска

  • Максимальная глубина вложенных подключений модулей — 2 уровня.
  • Максимальное количество зацикленных переходов при формировании страницы — 10.
