# Архив сайта otherside-world.ru

Перед вами архив авторских разработок на стыке метафизики и кибернетики. Здесь собраны инструменты для исследования сознания, перестройки мышления, изменения поведенческих алгоритмов и раскрытия внутренних возможностей человека.

В архив входят четыре авторские программы:

- **«Бдилка за Пасьянсом Медичи»** — исследование осознанности, управление вниманием и проектирование новых сценариев собственной реальности.
- **«Перелом Тетради Смерти»** — анализ привычных моделей мышления и поведения, поиск внутренних ограничений и изменение устоявшихся алгоритмов восприятия.
- **«Схемокодер Боевого Континента 2»** — развитие логического мышления и приобретение новых навыков через систему схемного программирования.
- **«Артефакт Изнаночки Мира»** — путь к созданию собственного наследия: возрождение своего дела, воплощение замыслов в реальность и сохранение результатов своего труда на тысячелетия.
