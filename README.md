# otherside-world.ru

Перед вами архив сайта о самопознании, изменении мышления и развитии внутренних возможностей человека.

В нём собраны авторские программы:

- **«Бдилка за Пасьянсом Медичи»** — для работы с осознанностью, вниманием и созданием новых жизненных сценариев.
- **«Перелом Тетради Смерти»** — для анализа и изменения привычных моделей мышления и поведения.
- **«Схемокодер Боевого Континента 2»** — для развития навыков и мышления через игровую систему программирования.
- **«Артефакт: Изнаночка Мира»** — о выборе, трансформации и создании собственного пути.
